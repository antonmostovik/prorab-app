# Прораб — мини-приложение Telegram

Экраны прораба для бота ежедневных отчётов со стройки: главный экран объекта и отчёт за смену.
Данные и проверки — на стороне бота (Google Apps Script), запросы подписываются Telegram (`initData`).

- `index.html`, `style.css`, `app.js` — приложение без сборки.
- `config.js` — адрес API бота.
- `?demo` — посмотреть экраны на вымышленном объекте без Telegram и без сервера.

Роли берутся из листа «Пользователи» бота: прораб — отчёт за смену, руководитель — сводка по объектам и заявки,
ПТО — проверка факта перед записью в базу и КСГ (`office.js`). Демо: `?demo`, `?demo=manager`, `?demo=pto`.
